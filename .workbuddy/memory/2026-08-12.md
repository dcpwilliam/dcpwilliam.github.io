## 新建 tcp-iot-server（Java TCP 服务器）
- 位置：`/Users/williamleon/Desktop/dcpwilliam.github.io/tcp-iot-server/`
- 功能：统一管理「设备 Device」与「人类 Human」两类 TCP 接入；人类绑定设备后可查询在线状态（ONLINE/OFFLINE），在线时下发三类指令 SEARCH / TASK / FORWARD，设备 RESP 实时回传人类。
- 结构：`TcpServer`（监听+线程池）、`Registry`（在线设备+人类↔设备绑定，ConcurrentHashMap）、`Session`（按行收发封装）、`ClientHandler`（协议路由）、`client/DeviceSimulator` + `client/HumanConsole`（测试客户端）。`run.sh` 一键编译运行（server/device/human 三模式）。
- 编译/运行用本机 Homebrew JDK：`/opt/homebrew/opt/openjdk/bin/{javac,java}`（系统未装 java）。
- 验证：端到端冒烟测试通过（设备在线→指令转发+回传；设备离线→OFFLINE/DEVICE OFFLINE）。
- 注意：人类秒发 bye 会竞态丢失 SENT/RESP 显示，交互场景无碍；HumanConsole 已用 hasNextLine 处理 stdin EOF。
