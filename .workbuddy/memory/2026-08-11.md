# 2026-08-11

## 构建微信小程序（机器人主题）
在 `wechat-miniprogram/` 下从零搭建了一个微信小程序，含 4 个 tabBar 页面：
- `pages/simulate`：迷宫模拟（递归回溯生成可解迷宫、上下左右移动、出口判定、步数统计、重置/换迷宫）；机器人 emoji 取自装备页配置。
- `pages/equip`：机型（机器狗/蜘蛛/螃蟹）+ 8 种配色选择，实时预览，写入 `robotConfig` 本地存储。
- `pages/mine`：8 项能力开关（网页爬虫/文档生产/逻辑判断/视觉追踪等），写入 `abilities` 本地存储。
- `pages/device`：模拟 IoT 同步，展示实体机器人固件/智能体/SDK 版本、电量、IP、能力标签。

数据通过 `wx.setStorageSync` 在页面间共享（装备→模拟机器人外观、能力→设备能力清单）。配置均为文本 tabBar（无图标 PNG）。appid 用 `touristappid` 可游客模式打开。所有 JSON/JS 已通过校验。

## 装备页新增 3D 动态窗口
- `pages/equip/robot3d.js`：纯 JS 轻量 3D 线框渲染器（canvas 2d，绕Y自转+透视投影+画家算法），含机器狗/蜘蛛/螃蟹三种模型，腿部位姿动画（走路步态、跳跃抛物线、落地屈膝），HUD 文本。
- 装备页嵌入 `<canvas type="2d">` 实时预览，提供 走路/跳跃/待机 控制；型号与配色切换同步到 3D 模型。
- 机械音效：`pages/equip/audio/` 下 mech_step.wav / mech_jump.wav / mech_idle.wav，由 Python 纯标准库合成（马达嗡鸣+伺服上扫+落地 click）。通过 `wx.createInnerAudioContext` 播放，失败时回退 `wx.vibrateShort`。
- 注意：小程序用 `wx.createSelectorQuery().in(this).select('#robotCanvas').fields({node,size})` 获取 canvas node 后 `canvas.requestAnimationFrame` 驱动循环。

## 能力装配页新增「低代码脚本」开关
- 新增 `utils/jsruntime.js`：**安全 JS 子集沙箱解释器**（纯 JS 自实现的 词法+语法+树遍历解释器，不使用 eval/new Function，因微信小程序运行时不支持 eval）。支持 变量/算术/比较/逻辑/三元/if-else/for/while/return/数组/对象/成员访问/函数调用（仅限作用域内置与 Math/JSON）/ ++ -- 前缀后缀自增，带 20 万步预算防死循环。支持的用户 API：`log()/print()/alert()/tone()`，内置变量 `event{name,data}` `robot{type,color}` `state` `Math` `JSON` `console`。入口 `runCode(code, {eventName, eventData, robot})` 返回 `{ok, error, output[], tones[], alert}`。
- `pages/mine/mine.js`：新增低代码开关（`lowCodeEnabled`）、JS 编辑器（textarea，绑定 `onCodeInput` 实时存 `lowCode` 存储）、触发场景选择（迷宫终点自动 / 仅手动）、「模拟触发」按钮（eventName='manual'）、输出控制台（logLines）。默认含示例脚本。存储键 `lowCode = {enabled, script, event}`。
- `pages/simulate/simulate.js`：机器人到达终点且 `lowCode.enabled && lowCode.event==='goal'` 时，调用 `runCode` 执行用户脚本（eventName='goal'，eventData.steps），通关弹窗关闭后展示「低代码脚本输出」弹窗；按脚本 `tone('jump'/'step')` 播放对应音效。
- 验证：node 跑通解释器 20+ 样例（含错误/死循环/未定义函数等负例）；复刻默认脚本在 manual/goal 两种触发下输出正确；所有 JS/JSON 通过校验。
- 关键约束：小程序不支持 eval，所以低代码必须用自实现解释器；用户代码无法访问 wx/全局对象，天然隔离。若需更复杂 JS（如自定义函数/for-in）可扩展 jsruntime。
